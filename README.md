# Conversor de Escalas Termométricas em Go

Programa desenvolvido em **Go** para converter o ponto de ebulição da água de Kelvin para graus Celsius, como parte dos estudos iniciais na linguagem.

## 🚀 Tecnologias Utilizadas
* [Go (Golang)](https://golang.org/)

## 💻 Como Executar

1. Certifique-se de ter o Go instalado na sua máquina.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto e execute o comando:

```bash
go run main.go
